# SenseFlight naming

Research: SenseFlight. Display project: SenseFlight-Web. Pure visual: SenseFlight-Vis (V). Multimodal: SenseFlight-VisOlf (VO).

Displayed model names: ConnectomeFlight-M-V and ConnectomeFlight-M-VO. Upstream FlyVis and FlyBody keep their original names.

The public entry point is `dist/index.html`. `dist/app.js` only controls presentation playback. This repository has no Python research package or training entry point.
